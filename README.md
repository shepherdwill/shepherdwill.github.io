# shepherdwill.github.io

Personal research website, served by GitHub Pages at https://shepherdwill.github.io.

Plain HTML and CSS, with no build step. To preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

## Layout

- `index.html`: the whole site (single page: intro, research, workshops, experience, awards)
- `assets/css/style.css`: all styling (colours at the top)
- `assets/img/`: photos
- `assets/papers/`: paper PDFs
- `assets/files/`: other documents (e.g. workshop agendas)

Push to `main` to publish.
